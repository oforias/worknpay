# WorkNPay - 10-Minute Video Presentation Script

## PART 2: PLATFORM DEMONSTRATION (6 minutes)

### Demo 1: Customer Journey - Search & Book (2 minutes)

**[SCREEN: Live platform - Home page]**

**Script**:
> "Now let me show you how WorkNPay works. I'll demonstrate the complete customer journey."

**Actions**:
1. **Home Page** (15 seconds)
   - "This is our mobile-first home page"
   - "Customers can browse service categories"
   - Show service category cards

2. **Search & Filter** (30 seconds)
   - Click on "Gadget Repair"
   - "Here customers can search and filter workers"
   - Apply filters: Location, Price range, Rating
   - "Results update in real-time"
   - Show worker cards with ratings and pricing

3. **Worker Profile** (30 seconds)
   - Click on a worker profile
   - "Each worker has a detailed profile"
   - Show: Bio, skills, ratings, reviews, portfolio photos
   - "Verification badges build trust"
   - Point out: ID verified badge, rating (4.8 stars), completed jobs

4. **Create Booking** (45 seconds)
   - Click "Book Service"
   - Fill booking form:
     - Select service: "Phone Screen Repair"
     - Choose date and time
     - Enter location
     - Add description: "iPhone 13 screen replacement"
   - "System calculates estimated price"
   - Show: Service price GHS 150 + Platform fee GHS 10.50 = Total GHS 160.50
   - Click "Proceed to Payment"

**Key Points to Highlight**:
- Mobile-responsive design
- Real-time filtering
- Transparent pricing
- Easy booking process

## PRESENTATION TIPS

### Before Recording

**Technical Setup**:
- [ ] Test screen recording software (OBS Studio, Loom, or Zoom)
- [ ] Ensure good audio quality (use external microphone if possible)
- [ ] Set up dual monitors (one for script, one for demo)
- [ ] Clear browser cache and cookies
- [ ] Prepare test accounts (customer, worker, admin)
- [ ] Have test data ready (services, bookings, reviews)
- [ ] Close unnecessary browser tabs and applications
- [ ] Set browser zoom to 100% or 125% for visibility

**Platform Preparation**:
- [ ] Seed database with realistic test data
- [ ] Create sample worker profiles with photos
- [ ] Add sample services with descriptions
- [ ] Create sample bookings at various stages
- [ ] Add sample reviews and ratings
- [ ] Test payment flow with Paystack test mode
- [ ] Verify all features are working

**Presentation Materials**:
- [ ] Create PowerPoint/Google Slides for Part 1
- [ ] Prepare high-quality screenshots
- [ ] Design professional graphics and charts
- [ ] Add WorkNPay branding consistently
- [ ] Export slides as PDF backup

### During Recording

**Delivery Tips**:
- Speak clearly and at moderate pace
- Show enthusiasm and confidence
- Maintain professional tone
- Pause briefly between sections
- Emphasize key features and benefits
- Use cursor to highlight important elements
- Avoid "um" and "uh" fillers

**Technical Tips**:
- Record in 1080p (1920x1080) minimum
- Use screen recording with webcam (picture-in-picture)
- Ensure good lighting for webcam
- Minimize mouse movements
- Click deliberately and slowly
- Allow UI animations to complete
- Pause 2 seconds before switching screens

**Timing Management**:
- Part 1 (Business Plan): 3 minutes
- Part 2 (Demo): 6 minutes
- Part 3 (Conclusion): 1 minute
- Practice to stay within 10 minutes
- Have a timer visible during recording

### After Recording

**Editing**:
- [ ] Trim any mistakes or long pauses
- [ ] Add intro and outro graphics
- [ ] Include background music (subtle, professional)
- [ ] Add text overlays for key points
- [ ] Include transitions between sections
- [ ] Add captions/subtitles for accessibility
- [ ] Export in high quality (1080p, 60fps)

**Quality Check**:
- [ ] Watch entire video for errors
- [ ] Check audio levels (consistent volume)
- [ ] Verify all features demonstrated clearly
- [ ] Ensure timing is within 10 minutes
- [ ] Test video on different devices
- [ ] Get feedback from a colleague
